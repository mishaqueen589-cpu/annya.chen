ANNY BIRTHDAY WEBSITE
======================

MOBILE + VIDEO FULLSCREEN VERSION

FILES
-----
index.html
style.css
script.js
video/birthday-video.mp4

VIDEO
-----
Put your birthday video inside the "video" folder.

The filename MUST be:

birthday-video.mp4

So the final structure should be:

Anny_Birthday_Website/
│
├── index.html
├── style.css
├── script.js
└── video/
    └── birthday-video.mp4

MOBILE
------
The website is responsive and designed for phones, tablets and desktop.
It includes:
- Mobile-friendly text sizes
- Touch-friendly buttons
- One-column birthday wish cards on phones
- Better spacing for small screens
- Safe-area support for phones with a notch/home indicator
- No horizontal scrolling

FULLSCREEN VIDEO
----------------
There is a "Fullscreen" button on the video.

It supports:
- Android Chrome
- Android browsers that support Fullscreen API
- Desktop browsers
- iPhone/iPad Safari video fullscreen fallback

IMPORTANT:
GitHub Pages must contain the video at exactly:

video/birthday-video.mp4

File names are case-sensitive on GitHub Pages.

GITHUB PAGES
------------
Upload the complete website folder contents to your GitHub repository.

Do NOT rename:
- index.html
- style.css
- script.js
- video
- birthday-video.mp4

If the video does not play, check that the file is actually uploaded and that its name is exactly:
birthday-video.mp4

Recommended video format:
MP4 (H.264 video + AAC audio)

OPEN LOCALLY
------------
Double-click index.html to preview the page.

For the best GitHub Pages test, open the published GitHub Pages link on your phone after uploading.

ENJOY 💛
